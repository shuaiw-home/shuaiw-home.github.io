Privacy Policy – Hermes Personal

Last updated: 23 October 2026

Hermes Personal is a private, single-user tool. Its only user is its owner.

What data it accesses

With the owner's consent, it accesses the owner's own Gmail, Google Calendar, Google Docs and Google Sheets through Google APIs, only to carry out the owner's requests.

How data is stored and shared

  • Data is processed on the owner's own computer.
  • Data is not sold, and is not shared with any third party for advertising or any other purpose.
  • Data from other people is not collected, because no one else can sign in.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
